## Description

An offline-first agent that translates unconstrained natural-language GIS
requests into executable Python scripts written against the modern
object-oriented `grass.tools` API of GRASS GIS. Generation is grounded in the
official GRASS 8.6 manual and verified deterministically by static analysis;
verified scripts are then executed in a headless GRASS session and repaired
from runtime feedback.
